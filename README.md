# 医療画像ビューア

DICOMまたはTIFF形式の医療画像を、3方向の断面と3Dボリュームで確認するデスクトップアプリケーションです。

## 動作環境

- Windows
- Python **3.11.x**

## 起動準備

必要なファイルはZIP形式でダウンロード済みであるものとします。

### 1. ZIPファイルを展開する

ダウンロードしたZIPファイルを、任意の場所に展開してください。以降は、展開後のフォルダーを作業フォルダーとします。

例:

```text
medical-app\
├── dicom_viewer.py
├── requirements.txt
├── lung_only.tif
└── ...
```

### 2. 仮想環境を作成して有効化する

PowerShellで展開先のフォルダーを開き、次のコマンドを実行します。

```powershell
cd C:\展開先\medical-app
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 必要なライブラリをインストールする

仮想環境を有効化した状態で実行してください。

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## アプリの起動

仮想環境を有効化した状態で、作業フォルダーから実行します。

```powershell
python dicom_viewer.py
```

アプリを終了するには、メニューの `ファイル` → `終了` を選択します。終了後も仮想環境を使用しない場合は、次のコマンドで無効化できます。

```powershell
deactivate
```

## 画像を読み込む

### DICOM

- 1枚のDICOMを開く: `ファイル` → `DICOM ファイルを開く`
- DICOMシリーズを開く: `ファイル` → `DICOM フォルダを開く`

DICOMシリーズを読み込む場合は、`.dcm`ファイルが入っているフォルダーを選択してください。読み込み後、3方向の断面画像が表示されます。

### TIFF

- マルチページTIFFを開く: `ファイル` → `TIFF ファイルを開く`
- TIFFシリーズを開く: `ファイル` → `TIFF フォルダを開く`

マルチページTIFF（例: `lung_only.tif`）または、複数の `.tif` / `.tiff` ファイルが入ったフォルダーを選択できます。TIFFを読み込むと、3Dボリュームレンダリングが自動的に開きます。

## 断面画像の見方と操作

画面には、左から次の3つの断面が表示されます。

- **Axial (XY)**: Z方向の位置を示す断面
- **Coronal (ZX)**: Y方向の位置を示す断面
- **Sagittal (ZY)**: X方向の位置を示す断面

各画像上のライムグリーンの線は、他の断面が交差する位置を示します。

### マウス操作

操作する断面画像の上にマウスポインターを置いてください。

| 操作                       | Axial       | Coronal     | Sagittal    |
| -------------------------- | ----------- | ----------- | ----------- |
| マウスホイール上下         | Y位置を移動 | Z位置を移動 | Z位置を移動 |
| Shift + マウスホイール上下 | X位置を移動 | X位置を移動 | Y位置を移動 |

現在位置は、画面下部の `スライス位置` に `Z / Y / X` の順で表示されます。

### コントラスト調整

画面下部のスライダーを操作します。

- **Window Level (WL)**: 明るさの中心（コントラストの基準）を調整
- **Window Width (WW)**: 表示する明るさの範囲を調整

## 3Dボリュームレンダリング

DICOMを読み込んだ後、`表示` → `3D ボリュームレンダリング` を選択すると3D表示を開けます。TIFFは読み込み時に自動で開きます。

3Dウィンドウでは次の操作ができます。

- 左クリックしながらドラッグ: 回転
- マウスホイール: 拡大・縮小
- `q`キー: 3Dウィンドウを閉じる

3Dウィンドウを閉じるまで、メインウィンドウは操作できません。
